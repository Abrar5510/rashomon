What is Rashomon?

Five AI readers predict what your function returns. We run it. Wrong predictions = confusing code.

📊 Misread rate % of predictions that were wrong (abstentions count as wrong)
📈 95% CI Wilson interval — lower bound >20% = statistically confusing
🤷 Disagreement Average distinct answers per probe — higher = readers disagree
✅ Clean witnesses Readers who got EVERY probe right (out of 5)
🐛 Bug fixes Git commits fixing bugs that actually changed this function
